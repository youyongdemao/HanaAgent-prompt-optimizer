# 提示词优化（Prompt Optimizer）

> 把随手写下的基础提示词一键重写成结构清晰、模型更好执行的高质量提示词。

Hana v2 应用。在输入框上方开一个面板，或者用画布上的卡片，写进去一段粗糙的话，按场景改写成能直接喂给模型的结构化提示词。结果不好就接着提要求，在上一版的基础上继续改。

## 功能

- **六种场景预设**：通用 / 编程 / 写作 / 图像 / 分析 / Agent，每种带各自的侧重项
- **自定义场景**：内置的场景之外可以自己加，能改名、写说明、删掉
- **输入框上方面板**：写一段基础提示词直接优化，不必离开对话
- **流式改写**：结果边生成边显示，随时可以停，已经收到的部分留着
- **左右对照与溯源链条**：原文与结果并排，链条上可以点回任意一版
- **迭代精修**：在上一版结果上继续提要求做增量修改，不用从头再来
- **候选改法**：按当前内容推荐改进方向，并标出这一版用过哪几种
- **复制回输入框**：把结果搬回去，方便换场景再优化，或手工再改两笔
- **模型工具 `optimize_prompt`**：在对话里直接说「帮我优化这段提示词」
- **检查更新**：比对指定 GitHub 仓库的 Release，有新版给更新日志与下载入口

## 用法

- **卡片**：把画布上的「提示词优化」放到需要的位置，写进去，点「优化」。`Ctrl + Enter` 是快捷键
- **对话**：让 Agent 调用工具，或直接说「帮我把这句话改成能喂给模型的提示词」
- **设置**：`设置 → 提示词优化`，管理场景清单、发布仓库，或手动检查更新

## 安装

1. 从 [Releases](https://github.com/youyongdemao/HanaAgent-prompt-optimizer/releases) 下载 `prompt-optimizer-v*.zip`
2. 在 HanaAgent「设置 → 扩展」中安装
3. 安装时逐项确认下面这些能力

| 能力 | 用途 |
|------|------|
| `app/tools.expose-to-model` | 向模型暴露 `optimize_prompt` |
| `app/models.infer` | 调用宿主 utility 模型做改写 |
| `app/input.panels` | 在输入框上方渲染优化面板 |
| `app/input.status` | 输入栏状态位 |
| `app/ui.clipboard-write` | 把结果复制回输入框 |
| `app/ui.open-external` | 打开 Release 页面 |
| `app/hooks.observe` | 观察会话输入 |

## 设置

- **场景清单**：六种内置场景之外自己加的那些，都可以改
- **发布仓库**：格式 `owner/repo`，检查更新时比对
- **检查更新**：手动比对 GitHub 上的最新版本

## 兼容性

| 项目 | 值 |
|------|-----|
| 宿主 | Hana ≥ 0.1013.0 |
| 装载形态 | App（manifest v2） |
| 网络 | 仅 `api.github.com`（GET），检查更新用 |

## 已知限制

- 改写只走宿主 utility 模型配置，不能指定 provider / 模型 / 密钥
- 应用不能自我更新：v2 应用的安装目录宿主只读，安装与升级都走「设置 → 扩展」
- 卡片不携带会话上下文，不跟随当前会话
